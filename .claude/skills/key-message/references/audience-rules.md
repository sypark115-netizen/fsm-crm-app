# Audience Rules

엔진은 장표 제목 → Story Role → 본문 순으로 주 독자를 추정한다(`slide_audience_ranked`). 틀리면 recommendation의 `audience`로 고친다.

| Audience | 관심 | 메시지 관점 | 피할 것 |
|---|---|---|---|
| CEO / 경영진 | 매출·비용·리스크·속도 | 성과를 기술 구축이 아니라 사업 변화로 | 기술 약어 2개 이상, 구성도 용어 |
| CIO / IT 임원 | 표준·거버넌스·TCO·리스크 | 기존 투자 보호, 단계적 전환, 운영 책임 | 근거 없는 "최적·최고" |
| CTO / CDO / AX 임원 | Architecture·데이터·확장성 | 재사용 가능한 구조, 확산 경로 | 막연한 "플랫폼화" |
| IT / AX 담당자 | 연동·성능·보안·일정 | 기존 시스템 유지 + API/Agent Layer 연결 | 추상 효과만 있는 문장 |
| 사업부장 | 매출·고객·현장 생산성 | 반복 업무를 줄이고 고객·매출 활동에 시간 | IT 내부 용어 |
| 현업 담당자 | 내 일이 어떻게 바뀌나 | "자료 찾고 정리하는 일은 AI가 먼저" | 경영 성과 용어 |
| 구매 / 재무 | 가격·계약·리스크 | 비용 구조, 조건, 산출 근거 | 과장, 모호한 범위 |

예시는 관점 예시일 뿐, 문장을 복사하지 않는다.
- C-Level: AI 도입의 성과를 기술 구축이 아니라 매출·비용·생산성 변화로 관리합니다.
- 사업부장: 반복 업무는 AI로 줄이고, 확보한 시간은 고객과 매출 활동에 집중합니다.
- IT/AX: 기존 시스템을 유지하면서 API와 Agent Layer를 단계적으로 연결합니다.
- 현업: 자료를 찾고 정리해 초안을 만드는 일은 AI가 먼저 처리합니다.
