# Governing Message / Key Message

발표본에서는 본문보다 GM을 먼저 평가한다. **본문을 지우고 GM만 읽어도 제안 Story가 연결되어야 한다.**

## 1. GM 추출

- `ingest.py`가 `gm_outline.md`에 GM 후보를 만든다. `gm_source`가 `title_placeholder`면 신뢰도 높음, `largest_font_top`/`topmost_text`면 렌더 이미지로 확인.
- 템플릿에 따라 "섹션명(작은 글씨) + 주장 문장(큰 글씨)" 2단 구조가 많다. 이때 **주장 문장**이 GM이다. 섹션명만 GM으로 잡혔으면 이미지 보고 바로잡는다.
- GM이 없는 장표(이미지만, 표만) → `NO SO-WHAT` 후보.

## 2. GM 평가 9문항

| # | 질문 | 실패 예 → 개선 방향 |
|---|---|---|
| 1 | Customer 중심인가? | "KT의 DC 역량" → "한빛은행 계정계를 계획정지 8시간 안에 옮기는 방법" |
| 2 | So What이 있는가? (주제명이 아니라 주장인가) | "네트워크 고도화 방안" → "대외계 회선을 이원화해 단일 사업자 장애에도 대외거래 중단 0" |
| 3 | 다음 장표와 연결되는가? | 앞 장 "Cutover 리스크" → 다음 장 "회사 소개" (단절) |
| 4 | Differentiation이 있는가? | 누구나 하는 일("이중화 구성") vs KT만의 방식 |
| 5 | Why KT와 연결되는가? | 차별화가 KT의 어떤 자산·경험에서 나오는지 |
| 6 | Evidence가 있는가 (같은 장표에) | GM의 주장을 본문이 증명하는가 |
| 7 | 너무 추상적인가? | "최적의", "안정적인", "고도화된" → 무엇이 얼마나 |
| 8 | 경쟁사도 쓸 수 있는가? | → 3절 Replaceability Test |
| 9 | AI가 쓴 것처럼 일반적이거나 부자연스러운가? | → 5절 |

좋은 GM의 형태: **[고객 문제/목표] + [KT의 방법] + [결과/근거]**, 한 문장, 2줄 이내.
예: "서버 이전과 회선 Cutover를 하나의 Runbook으로 통제해 계획정지 8시간 내 전환 — A금융사 1,180대 이전으로 검증"

## 3. Competitor Replaceability Test

1. 핵심 GM(전략·차별화·Why KT 장표)에서 "KT"를 Brief의 경쟁사명(없으면 "국내 대형 SI/MSP사")으로 바꿔 읽는다.
2. 문장이 **여전히 참이고 자연스러우면** → `DIFFERENTIATION FAILURE` 후보.
3. 교체하면 거짓이 되거나 어색해지는 요소(KT 고유 자산, 특정 실적, 특정 운영조직)가 있으면 통과.
4. 리포트에는 교체 문장을 그대로 보여준다. 평가위원 시점의 충격이 가장 큰 증거다.
   > "<경쟁사>는 차별화된 금융 Cloud 역량을 보유하고 있습니다" — 그대로 성립한다.

주의: KT 고유 요소가 *사실인지*는 AI가 판단하지 않는다. "통신·DC·회선을 직접 운영" 같은 요소가 자료에 근거 있으면 Differentiation 후보로 인정하되 Evidence 연결 여부를 따로 본다.

## 4. Storyline 판정

- GM01→GMn을 하나의 문단처럼 이어 읽는다. 접속어("그래서", "이를 위해", "그 근거로")로 이어지지 않는 지점 = `STORYLINE BREAK` 후보.
- Backbone(Customer→Differentiation→Why KT→Evidence→How→Impact) 대비 순서 역전·누락을 표로 정리한다.
- 같은 주장이 3장 이상 반복되면 Story가 정체된 것 (중복 GM은 `cross_check.json`의 `duplicate_gm`).
- Executive의 `storyline` 표: 각 GM과 Flag(`OK`/`BREAK`/`NO SO-WHAT`/`GENERIC`)를 한 줄씩.

## 5. AI스러운 표현 (GM과 본문 공통)

다음은 그 자체로 오류는 아니지만, 근거 없이 쓰이면 평가위원에게 "아무 말"로 읽힌다:
- 형용사 과잉: 혁신적인, 획기적인, 최적의, 최고의, 차별화된, 선도적인, 고도화된, 원활한, 효율적인, 안정적인
- 공허한 결과: 시너지 극대화, 가치 창출, 새로운 패러다임, 경쟁력 강화, 고객 만족 제고
- 구조 패턴: "~를 통해 ~를 실현합니다", "A, B, C를 아우르는", 3개 단어 나열 + "·", "단순한 ~이 아닌 ~"
- 번역투: "~함에 있어", "~에 대한 ~의 제공"

처방은 삭제가 아니라 **구체화**다: "최적의 회선 구성" → "대외계 회선 2개 사업자 이원화 (단일 사업자 장애 시 자동 우회)".
