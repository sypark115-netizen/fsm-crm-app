# Domain: Network / Telecom (백본, 대외계, 영업점, SD-WAN, 전용회선)

## 평가위원의 핵심 걱정
"회선 장애 한 번이 전 영업점·대외거래 중단이다. 이중화가 진짜 이중화인가?"

## 반드시 보여야 할 것
- 현행 대비 목표 구성도 (백본·DR·대외계·영업점·인터넷망 분리)
- **이중화의 실체**: 경로 이원화(물리 경로·국사), 사업자 이원화, 장비 이중화 — 무엇이 어디까지인가
- 망분리 구조 유지·변경 사항 — `REGULATORY VERIFY`
- 전환 계획: 영업점·대외기관 회선 전환 순서, 동시 전환 Risk, Rollback
- 품질 지표: 가용성, 지연, 장애 복구시간(MTTR), 모니터링 체계
- 보안: 구간 암호화, 접근통제, DDoS 대응

## KT 차별화 후보 (가설)
- 자체 망·국사 보유 → 물리 경로 이원화 설계 가능성 (Evidence: 경로도·실적)
- 전국 현장 인력 → 영업점 동시 전환·장애 출동 (Evidence: 인력·출동 SLA)
- 회선 + DC + 보안관제 통합 SLA

## Red Flags
- "이중화"가 같은 국사·같은 사업자 내 이중화 (단일 장애점 잔존)
- SD-WAN 등 기술 도입 "검토" 수준 (제안인지 아닌지 불명확)
- 경쟁 사업자 회선과의 이원화 요구가 있는데 KT 단독 구성 제안
