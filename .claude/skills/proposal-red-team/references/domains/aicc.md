# Domain: AICC (AI 컨택센터, 콜봇·챗봇, 상담 어시스트, STT/TA)

## 평가위원의 핵심 걱정
"상담 품질이 떨어져 민원이 늘면? 녹취·개인정보는? 상담사는 실제로 편해지나?"

## 반드시 보여야 할 것
- 대상 업무·콜 유형별 자동화 범위와 목표 지표 (자동 처리율, AHT, 상담사 후처리 시간, 고객 만족)
- 인식 성능: STT·의도 분류 정확도의 **측정 조건** (금융 용어·잡음·사투리), 개선 절차
- 상담사 전환(Fallback) 설계, 민원·취약계층 고려
- 녹취·상담 데이터의 개인(신용)정보 처리, 보관·파기 — `REGULATORY VERIFY`
- 기존 CTI·CRM·코어 시스템 연계
- 운영: 시나리오 관리, 학습 데이터 운영, 성과 리포트

## KT 차별화 후보 (가설)
- 운영 중인 대규모 AICC 레퍼런스의 실제 지표 (Evidence: 고객·지표·기간)
- 통신 인프라(콜 라우팅)와 AI의 통합

## Red Flags
- 데모 정확도를 운영 성능처럼 제시
- 자동화율 목표만 있고 산정 기준 없음
- 상담사·민원 관점 없음
