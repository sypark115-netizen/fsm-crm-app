# 교실 에어컨 세척 — 인스타그램 카드뉴스 (5장)

- `index.html` — 카드뉴스 원본(1080×1350, 4:5). 브라우저로 열면 5장이 세로로 보입니다.
- `export/card-1~5.png` — 인스타그램 업로드용 이미지(장당 1080×1350).
- `export/cardnews-5pages.pdf` — **캔바 가져오기용**. 카드 1장 = 1페이지, 텍스트·도형이 통이미지가 아닌 개별 요소로 들어갑니다.
- `caption.md` — 캡션 + 해시태그.
- `fonts/` — Pretendard(OFL 1.1).

## 캔바에서 편집
1. 캔바 → 업로드 → `export/cardnews-5pages.pdf` 가져오기 (5페이지 디자인으로 열림).
2. 점선 박스("사진 넣기")를 선택 → 현장 사진으로 교체.
3. 문구·색상은 캔바에서 직접 수정.

## 다시 뽑기
HTML 수정 후 `node render.js` (전역 playwright 필요) → `export/` 갱신.
