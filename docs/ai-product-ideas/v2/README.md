# AI 상품화 아이디어 100 — Version 2 (3개 타깃 통합 양식)

- 기준일: 2026-09-26
- 대상: 중소기업 · 소상공인 · B2B 영업사원

## 1. 요청 의도 재정의

V1 세 파일의 목적은 같습니다. "타깃별로 **돈 받고 팔 수 있는 AI SaaS 상품 후보 100개**를 뽑고, **무엇부터 만들지** 결정하는 것"입니다.

그런데 파일마다 양식이 달라서 서로 비교할 수 없었습니다.

- 중소기업 파일: 8시트, 점수 있음
- 소상공인 파일: 1시트, 점수 없음
- 영업사원 파일: CSV, 여정 15개만 있음

V2는 세 파일을 **같은 10개 시트, 같은 22개 컬럼, 같은 채점식**으로 다시 만들었습니다.

## 2. V1 컨설턴트 진단 요약

| 구분 | 중소기업 V1 | 소상공인 V1 | 영업사원 V1 |
|---|---|---|---|
| 형식 | xlsx 8시트 (가장 체계적) | xlsx 1시트 + 가이드 | CSV (Top15 여정만) |
| 강점 | 수식 연동, Top15 개발가이드·여정 | 현장 언어, 현실적 요금(4,900~99,000원), 100개 전부 GitHub·프롬프트 | 사용자여정·승인 포인트가 가장 구체적 |
| 약점 | 점수 근거 없음, 중복 6쌍, 가격 과대·획일 | 순위 없음, 분류 혼선, 1회성 프롬프트 항목, 근거·계산기 없음 | 100개 본체 없음, 순위 근거 없음, 가격·개발법 없음 |
| V2 조치 | 5기준 분해(V1 점수 그대로 재현), 6쌍 통합, 6개 신규, 가격 하향 | 7영역 재분류, 11건 통합, 5건 삭제, 16개 신규, 채점·Top15·여정 신설 | 100개 DB 신규 작성, 채점 후 Top15 재선정, 좌석형 가격 |

각 파일의 `00_V1_진단` 시트에 항목별 근거와 변경 로그(통합·삭제·신규·명칭 변경)가 있습니다.

## 3. 공통 양식 (3개 파일 동일)

| 시트 | 내용 |
|---|---|
| 00_V1_진단 | 요청 의도, 장단점 진단표, V1→V2 변경 로그 |
| 01_Executive | 시사점, 가격 원칙, 첫 상품 제안, KPI 카드, Top15 (02 시트 수식 연동) |
| 02_AI_100 | 22개 컬럼 메인 DB (순위, 아이템, 영역, 실사용자, 가치유형, 데이터, 5기준 점수, 효과점수, 등급, KPI, 도입기간, 가격모델, 과금 단위, Basic/Pro 월요금, 구축비, 근거, V1 출처) |
| 03_Pricing_Model | P1~P10 공통 코드. 가격대는 타깃별로 다름 |
| 04_Pricing_Calculator | 경제가치 → 권장 요금·ROI, 타깃 예산 범위 자동 판정 |
| 05_Category_Map | 영역별 수·평균·최고점·S/A+ 수 (수식) |
| 06_Sources | 근거 코드 S1~S15와 인용 수 (수식) |
| 07_Top15_Dev_Guide | 노코드 PoC → GitHub → 프롬프트 → AI코딩, MVP 4주 |
| 08_User_Journey | 인풋, 5단계 절차, 화면 목업, 승인 포인트, KPI |
| A1_V1_원본 | V1 원문 보존 (비교용) |

채점 방식은 세 파일 모두 같습니다.

- **입력**: 경제효과·적용범위·성과속도·구현용이성·KPI측정성을 각각 1~5점으로 넣습니다. 파란 글씨 셀입니다.
- **환산**: 수식 `=G*8 + H*4 + I*3 + J*2 + K*3`으로 100점 만점이 됩니다.
- **등급**: S는 95점 이상, A+는 89점 이상, A는 80점 이상입니다.

## 4. 타깃별 Top 5 & 첫 상품

| 순위 | 중소기업 (회사 정액) | 소상공인 (매장 월구독) | 영업사원 (좌석형) |
|---|---|---|---|
| 1 | 견적·제안서 자동화 (98) | 리뷰 답글 자동 생성 (98) | 미팅 녹음 → CRM 자동 기록 (98) |
| 2 | 영업 후속조치 자동화 (98) | 재방문 알림톡 자동화 (95) | Follow-up 메일 초안 (95) |
| 3 | 사내 지식검색 Q&A (98) | AI 상담·예약 챗봇 (95) | 콜드메일 대량 개인화 (94) |
| 4 | 증빙 자동 전표화 (95) | 영수증·카드 자동 장부 (95) | 제안서 초안 자동 생성 (91) |
| 5 | CS 티켓 분류·답변초안 (94) | 노쇼 방지 알림톡 (94) | 정체 딜 알림·다음 액션 (91) |
| 가격대 | Basic 30만~200만원/월 | Basic 4,900~29,000원/월 | 좌석 4,900~49,000원/월 |

**세 타깃에 공통으로 걸리는 기회가 있습니다.**

"미팅 기록 → 후속 메일 → 제안·견적"은 세 타깃 모두 Top 5 안팎에 있습니다. 엔진 하나를 만들어 가격만 다르게 파는 게 가장 효율적입니다.

- 영업사원에게는 좌석형으로
- 중소기업에게는 회사 정액으로
- 소상공인에게는 고객응대팩으로

또 이 엔진은 현재 레포인 FSM-CRM에 바로 붙일 수 있는 기능입니다.

## 5. 가정과 한계

- 점수와 가격은 공개 연구와 SaaS 공식 가격(06 시트)을 참고한 **컨설팅용 가정**입니다. 실제 효과는 PoC로 검증해야 합니다.
- 중소기업은 통합 6개와 신규 6개만 새로 채점했고, 나머지 88개는 V1 총점을 그대로 재현했습니다. 소상공인과 영업사원은 V1에 점수가 없어서 100개 전부 새로 채점했습니다.
- 파일을 다시 만들려면 `build/`에서 `python3 make_all.py`를 실행합니다. openpyxl이 필요합니다.
